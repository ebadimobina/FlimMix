## ✨ Highlights

- **⚡ Blazing Fast & Unrestricted:** Powered by the open TVMaze public database. Instant loading with zero account requirements, no paywalls, and no region blocks.
- **🏷️ Instant Genre Browsing:** Filter top-rated and popular titles across Sci-Fi, Drama, Action, Comedy, Crime, Animation, and more with a single tap.
- **🌓 Themes for Day & Night:**
  - **Cinematic Dark:** Deep obsidian theme crafted for late-night viewing.
  - **Pure AMOLED Black:** True `#000000` pitch black background for maximum OLED battery savings.
  - **Clean Light:** Crisp high-contrast theme for daytime readability.
- **📑 Personal Library & Watchlist:**
  - Save titles into **Favorites** ❤️, **Watchlist** 📑, or **Watched** ✅.
  - **Backup & Restore:** Export your saved library as JSON or import it anytime — your data stays strictly on your device.
- **🎭 Complete Cast & Show Details:**
  - High-res posters, backdrop artwork, and ratings.
  - Cast members with photos and character names.
  - Recommended titles ("More Like This") based on your favorite genres.
  - Direct **Trailer** button to watch trailers instantly.
- **🔍 Smart Search:** Find movies and series instantly with real-time search and rating filters.
- **🔒 100% Privacy & Tracker-Free:** No advertisements, no analytics, no third-party tracking, and no telemetry.

## 🛠️ Built With

- **Flutter & Dart** – Cross-platform mobile framework
- **GetX** – State management and navigation
- **TVMaze REST API** – Public, free show directory
- **GetStorage** – Fast, local offline data persistence

## 💻 Building from Source

For developers who want to run the project locally:

```bash
git clone https://github.com/ebadimobina/filmmix.git
cd filmmix
flutter pub get
flutter run
```
